# AnimeCatalogue

Site web de gestion d'une collection d'animés en JavaScript natif.

## Fonctionnalités

- Affichage de la collection en cartes
- Recherche en temps réel par nom
- Tri par note (croissant / décroissant)
- Ajout d'un animé via formulaire
- Suppression avec confirmation

## Technologies

- HTML5, CSS3
- JavaScript
